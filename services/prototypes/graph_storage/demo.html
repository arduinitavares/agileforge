What changes when the data is a graph?

Does graph storage simplify dependency analysis, and does it fix Story replacement by itself?

This page has two parts. The interactive model below is a simulation of the lifecycle rule. The measurements further down come from actual scratch SQLite and Neo4j databases. Neither part connects to your AgileForge installation.

1. Explore the replacement rule

B depends on A. D depends on B. C is A's replacement. Arrows point from dependent to prerequisite. Both database choices can represent exactly this state.

2. Compare the query work

Identical synthetic entities and relationships are loaded into SQLite and Neo4j. A Python graph rebuilt from the SQLite tables gives a third result for comparison. Query results must agree before a timing is recorded.
