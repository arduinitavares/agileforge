# Historical design records

The dated plans and specifications below this directory are historical records,
not current runtime guidance. Where they describe the retired Authority
architecture, [ADR 0005](../adr/0005-use-accepted-specification-as-delivery-contract.md)
and the 2026-08-21 accepted-Specification design supersede them.

Do not copy obsolete modules, schemas, commands, or lifecycle steps from these
records into production.
